# Motus

Eine kleine Web-App, um langfristige Ziele mit dem Alltag zu verbinden: Aufgaben pro Tag in eine Reihenfolge bringen, eine Aufgabe nach der anderen im Fokus abarbeiten und erfassen, wie viel Zeit wirklich in die eigenen Ziele fließt.

- Läuft komplett im Browser, auch offline, und lässt sich auf Handy und Computer als App installieren.
- Keine Anmeldung, kein Server, keine Datenbank, keine externen Dienste.
- Alle Daten bleiben im Browser des jeweiligen Geräts. Optional kann ein eigener Speicher (Dropbox oder WebDAV) zum Abgleich zwischen Geräten verbunden werden.

## Dateien

| Datei | Zweck |
|---|---|
| `index.html` | Die komplette App |
| `manifest.webmanifest` | Name, Farben und Symbole für die Installation |
| `sw.js` | Offline-Unterstützung |
| `*.png` | App-Symbole |
